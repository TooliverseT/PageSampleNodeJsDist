Vite base 경로와 자산 URL

개발 · 목록

GitHub Pages의 프로젝트 URL은 https://<user>.github.io/<repo>/ 형태입니다. 빌드 base: '/' 로 끝나면 index.html 이 /assets/... 를 불러오는데, 이 경로는 github.io 루트에 있어 404가 나 흰 화면이 될 수 있습니다.

base 를 저장소 경로에 맞추거나, base: './' 같이 상대 경로 를 쓰면 자산 URL이 맞게 뜹니다. 팀/저장소가 바뀌면 base 와 Pages 설정을 같이 갱신하세요.

배포 후 Network 탭에서 index-*.js / CSS 응답이 200인지 먼저 보면 됩니다.
